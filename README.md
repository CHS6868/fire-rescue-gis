# 🚒 FireRescue GIS

**A Web-Based Fire Incident Monitoring and Emergency Resource Planning Simulation System**

## 📖 Project Overview

FireRescue GIS is a collaborative software engineering project that aims to develop a web-based Geographic Information System (GIS) for simulating fire incident monitoring and emergency resource planning.

The application will integrate real-world geographical maps with simulated fire incidents, fire stations, fire trucks, and fire hydrants.

Users will be able to visualize simulated incidents, explore nearby fictional emergency resources, examine road routes, and monitor incident status changes through an interactive dashboard.

**Project Status:** 🟡 Planning & Requirements Analysis

> **Disclaimer:** This project is developed for educational and simulation purposes only. It is not intended for real emergency dispatch or operational firefighting decisions. All fire incidents and emergency resource records are simulated.

## 🎯 Project Objectives

1. Develop an interactive GIS dashboard using React.
2. Implement simulated fire incident management.
3. Visualize fictional fire stations, trucks, and hydrants on a real-world map.
4. Integrate a routing API to explore and compare road routes.
5. Implement real-time incident monitoring using WebSocket technology.
6. Apply software engineering practices, including requirements engineering, system design, testing, version control, and deployment.

## ✨ Planned Features

### 1. Interactive GIS Dashboard
- Real-world geographical map
- Interactive markers and information popups
- Map zooming, panning, and layer filtering

### 2. Fire Incident Management
- Manual creation of simulated fire incidents
- Incident severity and status management
- Incident history and tracking

### 3. Emergency Resource Management
- Fictional fire station management
- Simulated fire truck records
- Fictional fire hydrant visualization
- Basic nearby-resource exploration

### 4. Route Planning
- Integration with an external routing API
- Road route visualization
- Estimated travel time and distance
- Comparison of simulated route alternatives

### 5. Real-Time Monitoring
- WebSocket-based incident notifications
- Real-time dashboard updates
- Synchronization across connected users

### 6. Authentication & Reporting
- Role-based access control
- Incident history
- Dashboard statistics
- Simulation reports
